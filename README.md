# 科研人生 · v0.2 秋日手记

一款以国内博士培养和高校青年教师工作为背景的中文文字模拟游戏。六专业全部可选，支持博士 4 年 8 学期、最长 12 学期延期培养，以及高校青椒六年聘期的完整可玩流程。

## 开始游戏

- 在线试玩：<https://jijingsong1-ops.github.io/research-life/>。直接分享这个网页链接，手机和电脑浏览器都可以打开，无需安装。
- GitHub 仓库：<https://github.com/jijingsong1-ops/research-life>。
- 直接双击本目录的 `index.html`，即可游玩，无需安装依赖、注册或联网。
- 推荐使用固定本地地址保存进度：在本目录运行 `node serve.cjs`，访问 <http://127.0.0.1:4173>。
- 浏览器会自动保存每个行动、事件选择和投稿后的状态。浏览器、域名与端口不同，存档互不相通；隐私模式或禁用本地存储时可能不能保存。
- 本版在当前浏览器保留一份当前存档和一份上一局 / 替换前备份。右上角「存档管理」支持 JSON 导出、导入和恢复备份；「人生手记」可另行导出文字经历。没有远程账户或服务器存档。
- v0.1 的合法存档可继续使用，首次读取会补入节奏、机会记录、行动计划等新增字段，不必重新开局。

### 在线发布与手机使用

- GitHub Pages 从 `main` 分支根目录发布；推送更新后由 GitHub 自动更新网页。发布前运行 `npm test` 检查全部专业和流程。
- 如需迁移到其他静态托管服务，`npm run build` 可生成 `dist/`。该独立网页包仅包含游戏页面、脚本、样式和两张插画；GitHub 仓库保留完整开发源文件。
- 界面适配手机竖屏与横屏，支持刘海屏安全区、固定底部导航和行动栏；小按钮采用至少 44px 的触摸区域，手机下拉框避免因小字自动放大。
- 手机上可点底栏「安排本学期」跳到行动区，再用「帮我安排」生成可调整的计划。每次执行后有浮动反馈，长弹窗可独立滚动。
- 在线版与本地版、不同手机之间的存档互相独立。如需换设备，在「存档管理」导出 JSON 后，到另一台设备导入；不提供云同步。

### 存档与备份

1. 点右上角存档图标，选择「导出当前存档」，会下载 `科研人生-存档.json`。换浏览器或清理本地数据前，先保存这一文件。
2. 选择「导入存档」，上传不超过 3 MB 的游戏 JSON 文件。游戏先检查内容并显示专业与阶段，确认后才替换当前进度；格式无效时不会改变当前游戏。
3. 领取新一局入学通知书、确认导入或恢复备份前，当前进度会被写入上一份备份。仅浏览专业选择页不会覆盖现有进度，可点击「继续上一次的旅程」返回。
4. 「恢复上一份备份」会先展示专业与阶段，再由玩家确认恢复；当前进度与备份交换，因此可返回刚才的旅程。这里只保留最近一份备份，不是完整的多存档列表。
5. 若浏览器不允许本地存储，自动保存和本机备份可能失败，界面会提示。此时使用 JSON 导出保留进度；无法读取的旧存档也可先导出原始文件，不会被自动删除。

## 本版内容

- 理工科：计算机、电子信息、应用数学。
- 文科：汉语言文学、马克思主义理论、新闻传播学。
- 每专业三个初定研究方向，具有不同的研究量、最低周期、资源消耗、五项审稿指标和专业训练要求。
- 公共事件 8 条，专业事件每专业 8 条，共 56 条、112 个有代价的随机事件选项。同一事件池抽尽前不重复。
- 另有 12 项可主动选择的机会、24 个机会分支，涉及读书会、研究协作、社区分享、同伴支持、职业探索与六专业实践。每回合最多参与一项，每项占 1 行动。
- 三种学期节奏、可预览并批量执行的行动计划、随阶段变化的下一步建议，以及期末资源与成果回顾。
- 博士：研读 → 定方向 → 开题 → 科研 → 投稿返修 → 学位论文 → 盲审 → 答辩 → 择业；可延期或主动退出。
- 青椒：教学、指导、研究项目、横向 / 教改课题、投稿与终期评审。汉语言文学有专著 / 古籍整理章节；马克思主义理论有思政教改课题。
- 隐藏学术道德与人际属性，支持延迟规范质疑、撤回成果、调查认定后的学术道路终止。
- 12 个结局。高校分支继续六年；博后、企业和体制内行政在去向确定后收束，未扩展为独立职业阶段。
- 统一纸本与手绘场景风格，适配桌面与窄屏；键盘可访问按钮与表单；美术文件随项目本地保存，不依赖在线素材加载。

## 第一次怎么玩

1. 选择专业与初定研究方向，领取入学通知书。开局可先读「30 秒玩法」，入学后书桌上的三步提示也能帮助上手；提示可收起，右上角「怎么玩」随时可重看。
2. 每学期有 4 次行动。先看当前建议，再把想做的事务加入计划；核对精力、健康与经费变化后点「执行安排」。不确定时可点「帮我安排」，它只生成可调整的计划，不会立即消耗资源。
3. 第一次玩可保持「稳步推进」。想加快研究时选「集中攻坚」，身体吃紧时选「休整蓄力」；节奏只能在本回合尚未行动时调整，切换不会立即送资源。
4. 每回合有最多三项适用的主动机会。可以选一项加入研究之外的经历，也可以全部跳过，保留行动做主线。
5. 留出期末精力。每回合末依次处理公共事件和专业事件；有些事件需要经费。如果不想或不能承担分支成本，可延期协调，但会损失健康、关系与研究进度。
6. 工作量和最低周期同时达标后生成稿件。书桌上的「规范投稿」默认使用本专业中档层次和规范写作，消耗 1 行动、14 精力；要更换层次或策略时，再到论文工作台自选。返修也可直接在书桌处理。
7. 注意「毕业里程碑」。开题、专业训练、积累、成果、论文和盲审都不能遗漏。第 8 学期起通过答辩才能毕业。
8. 进入高校后，每年教学、第二年起指导学生。博士阶段已录用论文不重复计入聘期；聘期内新录用成果计入本局合同考核。

### 节奏、计划与主动机会

| 节奏 | 对行动的影响 | 需要承担的代价 |
| --- | --- | --- |
| 稳步推进 | 保持原有研究、研读和休息效果 | 没有额外加速，按正常周期积累 |
| 集中攻坚 | 每次专业研究额外 +1 研究进度 | 每次研究额外消耗 5 精力、3 健康 |
| 休整蓄力 | 每次休息额外 +5 健康 | 每次研究进度 −1，最低仍为 1；每次研读积累 −2 |

- 节奏不会免除最低研究周期。数学即使完成工作量，也仍需等待必要的理论积累时间。
- 计划按排列顺序执行，因此可以先休息再研究、先开题再写论文。可以移除事务，再按需要的顺序添加；加入计划不消耗资源，实际执行才扣除行动。某一步不可执行时，整个计划不扣除资源。
- 盲审和答辩可能改变培养阶段，必须排在计划最后。投稿、返修、主动机会和期末事件单独处理；已有未执行计划时，先执行或清空计划，再进行这些操作。
- 预览展示已知行动成本与收益，不提前揭晓项目立项、盲审等随机结果，也不允许预支尚未拿到的项目经费。实际结算以执行后的记录为准。
- 下一步建议会考虑健康与精力、阶段节点、在投稿件和年度责任。它帮助辨认优先事项，不会替玩家自动选择伦理分支或职业去向。
- 主动机会按专业、博士 / 青椒阶段与必要条件开放。写作互助需先通过开题，职业探索从博士第 5 学期起开放。机会分支的效果立即结算，同回合不能反复刷取。
- 机会推进的研究量不能替代毕业要求中的专业训练次数。每回合的两条随机事件仍保留，主动机会不会增加强制事件弹窗。
- 每次执行安排、投稿或参与机会后，会显示即时变化。学期 / 年度结束后另有六维属性、成果积分与关键消息回顾；结算后的下期精力恢复不会伪装成本期收益，回顾记录随存档保留。

### 投稿、项目与盲审数值

- 五维稿件基础质量：每项 `clamp(round(积累 × 0.68 + 20 + U[0,15)), 15, 96)`。马理论的导向规范项额外加入 `人际 × 0.15`，用于抽象政策沟通经验。
- 高、中、基础档分别计 3 / 2 / 1 分；规范写作耗精力 14、各维质量 +4。过度拔高耗 8、质量 +8、道德 −16、风险 +14；注水 / 蹭热点耗 6、质量 +6、道德 −20、风险 +18；伪造耗 4、质量 +17、道德 −38、风险 +38。每次投稿额外占 1 行动，质量最高 98。
- 常规录用概率：`clamp(0.38 + (质量均值 − 50) × 0.009 + 档次修正 + 复审修正, 0.16, 0.88)`。高档修正 −0.13、中档 0、基础档 +0.16；第二轮起 +0.10。常规随机值未落入录用区间、但小于录用率 +0.32 时返修，否则退稿。
- 文科另抽导向 / 刊物适配退稿：马理论 11%，其他文科 3.5%；优先于常规审稿结果。这里是剧情概率，不是现实统计。
- 返修耗 1 行动、18 精力、3 健康，积累 +4、稿件各维 +9，下一回合复审。退稿可调整并再次投稿。所有周期均按游戏回合计算。
- 项目申报概率：`clamp(0.30 + 积累 × 0.003 + 人际 × 0.002 + 马理论修正, 0.20, 0.82)`；马理论修正 +0.12。博士获资助额度：电子 10 万、其他 5 万；青椒：电子 22 万、计算机 14 万、其他 9 万。项目名表示本局相应层次的项目，不保证真实资格或实际金额。
- 横向 / 教改 / 思政教改课题与普通项目共用每年一次申报机会，声望需 ≥20，成功率 `0.55 + 人际 × 0.002`。获批理工额度 8 万、文科 4 万，承担更高精力与健康成本。获批后简化为本回合完成组织与交付，不另模拟完整合同执行。
- 普通项目首项采用相应青年项目叙事，获批后后续转为省部级 / 校内项目，避免反复获得同一种青年项目的错误暗示。
- 汉语言文学青椒可选择专著 / 古籍整理章节：每次耗 1 行动、20 精力、4 健康、0.5 万经费，积累 +4；三次后成稿送评，首次与重投至少等 2 年。按中档成果评议与计分，录用 +2；返修后等 1 年。章节不冒用 CSSCI 期刊标识。
- 盲审基本通过率：`clamp(0.72 + (积累 −55) × 0.006, 0.65, 0.95)`。道德 <55 时先有 50% 概率要求规范修改；未通过则论文退回 75，下学期可重审。
- 期末规范核查触发率：`min(0.8, 风险/160)`。触发且道德 <45 或风险 ≥60 时进入调查认定结局；否则声望 −12、好感 −8、健康 −7，并撤回一份有风险的成果。合规的零风险玩家不会凭空触发此系统。
- 期末常规健康 −2；数学尚无录用成果时 −5。第 9–12 学期每回合额外健康 −3、好感 −2；第 12 学期结束仍未毕业则结束培养。

## 写实边界与资料依据
